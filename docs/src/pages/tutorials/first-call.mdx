# 1. Your First Contract Call

In [Getting Started](/getting-started), we returned a hard-coded `42`. Real contracts take **calldata**, emit **logs**, and sometimes **revert** with an error payload.

In this tutorial, you will build a 19-byte contract that:
1. Reads two 32-byte integers `a` and `b` from calldata.
2. Adds them (`a + b`).
3. Emits a `LOG1` event carrying the sum.
4. Returns the sum as a 32-byte word.

Then we will deliberately trigger a `REVERT` and an `OutOfGas` error so you can see the exact difference inside `CallResult`.

## Design the bytecode before touching Zig

<MentalModel title="How the EVM sees calldata, memory, and logs">
Think of a `Frame` as three separate workspaces:
- **Calldata** is a read-only byte slice passed in by the caller (`CALLDATALOAD` reads 32 bytes at a time, zero-padding past the end).
- **Memory** is scratchpad RAM for this call only (`MSTORE` writes a 32-byte word so `LOG1` and `RETURN` can slice bytes out of it).
- **Logs** are append-only receipts stored on `Evm.logs` — kept on `RETURN`, discarded on `REVERT`.
</MentalModel>

Here is our 19-byte adder contract:

```text
PC   Opcode        Stack after (top on left)         What happens
───────────────────────────────────────────────────────────────────────────
00   PUSH1 0x00    [0]                               offset 0
02   CALLDATALOAD  [a]                               read calldata[0..32]
03   PUSH1 0x20    [32, a]                           offset 32
05   CALLDATALOAD  [b, a]                            read calldata[32..64]
06   ADD           [a+b]                             wrapping 256-bit add
07   DUP1          [a+b, a+b]                        keep a copy for later? no, store once
08   PUSH1 0x00    [0, a+b, a+b]                     memory offset 0
0a   MSTORE        [a+b]                             memory[0..32] = a + b
0b   POP           []                                clean stack (or reuse as topic!)
```

Wait — look at PC `07` and `0b`! Why throw away the extra copy on the stack when `LOG1` wants a **topic**? If we push a topic tag (say `0xdead`), we can drop `DUP1`/`POP` and save 2 bytes and 5 gas!

Even cleaner — 17 bytes total:

```text
00  PUSH1 0x00    # calldata offset 0
02  CALLDATALOAD  # stack: [a]
03  PUSH1 0x20    # calldata offset 32
05  CALLDATALOAD  # stack: [b, a]
06  ADD           # stack: [sum]
07  PUSH1 0x00    # memory offset 0
09  MSTORE        # memory[0..32] = sum; stack: []
0a  PUSH2 0xdead  # topic0 = 0xdead (event tag)
0d  PUSH1 0x20    # log data length = 32 bytes
0f  PUSH1 0x00    # log data offset = 0
11  LOG1          # emit log(topic0=0xdead, data=memory[0..32])
12  PUSH1 0x20    # return length = 32
14  PUSH1 0x00    # return offset = 0
16  RETURN        # return memory[0..32]
```

## Run it in Zig

```zig
const std = @import("std");
const guillotine = @import("guillotine_mini");
const voltaire = @import("voltaire");

pub fn main() !void {
    const Evm = guillotine.Evm(.{});
    var vm: Evm = undefined;
    try vm.init(
        std.heap.page_allocator,
        null,
        .CANCUN,
        null,
        voltaire.ZERO_ADDRESS,
        0,
        null,
    );
    defer vm.deinit();

    const target = voltaire.Address.fromU256(0x100);
    const bytecode = [_]u8{
        0x60, 0x00,       // PUSH1 0
        0x35,             // CALLDATALOAD
        0x60, 0x20,       // PUSH1 32
        0x35,             // CALLDATALOAD
        0x01,             // ADD
        0x60, 0x00,       // PUSH1 0
        0x52,             // MSTORE
        0x61, 0xde, 0xad, // PUSH2 0xdead (topic0)
        0x60, 0x20,       // PUSH1 32 (log size)
        0x60, 0x00,       // PUSH1 0  (log offset)
        0xa1,             // LOG1
        0x60, 0x20,       // PUSH1 32 (return size)
        0x60, 0x00,       // PUSH1 0  (return offset)
        0xf3,             // RETURN
    };
    try vm.code.put(target, &bytecode);

    // Pack two big-endian 32-byte words: a = 17, b = 25
    var input: [64]u8 = undefined;
    std.mem.writeInt(u256, input[0..32], 17, .big);
    std.mem.writeInt(u256, input[32..64], 25, .big);

    const result = vm.call(.{ .call = .{
        .caller = voltaire.ZERO_ADDRESS,
        .to = target,
        .value = 0,
        .input = &input,
        .gas = 100_000,
    } });

    std.debug.assert(result.success);
    const sum = std.mem.readInt(u256, result.output[0..32], .big);
    std.debug.print("sum={d}, logs={d}, gas_used={d}\n", .{
        sum,
        result.logs.len,
        result.gasConsumed(100_000),
    });
    std.debug.print("log[0].topic0=0x{x}\n", .{result.logs[0].topics[0]});
}
```

## Now compare `REVERT` vs `CallError`

Swap the final opcode `0xf3` (`RETURN`) for `0xfd` (`REVERT`) and run again. Look at what changes in `CallResult`:

| Field | `RETURN` (`0xf3`) | `REVERT` (`0xfd`) | `OutOfGas` / `InvalidJump` |
| --- | --- | --- | --- |
| `result.success` | `true` | `false` | `false` |
| `result.gas_left` | unspent gas | **unspent gas** | `0` (all gas burned) |
| `result.output` | return bytes (`42`) | **revert payload (`42`)** | empty (`&.{}`) |
| `result.logs` | 1 log (`0xdead`) | **empty** (logs rolled back!) | empty |
| `result.error_info` | `null` | `null` | error name (e.g. `"OutOfGas"`) |

<WatchOut title="Do not keep pointers to result.output after vm.deinit()">
`result.output`, `result.logs`, and `result.error_info` are allocated inside `vm.arena`. If you return a `CallResult` from a helper function that calls `defer vm.deinit()`, clone it first:

```zig
var owned = try result.toOwnedResult(caller_allocator);
defer owned.deinit(caller_allocator);
```
</WatchOut>
