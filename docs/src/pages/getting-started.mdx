# Getting Started

In five minutes you will compile Guillotine Mini, run real EVM bytecode from Zig, watch 18 units of gas disappear one opcode at a time, and trigger your first controlled failure.

## Prerequisites

| Tool | Version | Why it is required |
| --- | --- | --- |
| **Zig** | `0.15.1+` (CI uses `0.15.2`) | Compiles the EVM, tests, native archive, and WASI module |
| **Rust / Cargo** | Stable + `wasm32-unknown-unknown` (for WASM) | Builds Voltaire's Rust crypto static libraries (`blst`, BN254, KZG) |
| **Adjacent `../voltaire` checkout** | Pinned in `native-dependencies.json` | `build.zig.zon` resolves `voltaire` as a sibling path dependency |
| **Node.js** | `22+` (optional) | Runs `zig build test-wasm` and `examples/wasm.mjs` |
| **Python 3 + `uv`** | Optional | Generates `execution-specs` fixtures for `zig build specs` |

<WatchOut title="Cargo is not optional">
Even though Guillotine Mini is written in Zig, Voltaire links Rust cryptographic archives (`blst`, BN254, KZG) during `zig build`. Make sure `cargo` is on your `PATH`. For WebAssembly builds, install the WASM target once:

```sh
rustup target add wasm32-unknown-unknown
```
</WatchOut>

## Build from source

Clone the repository alongside `voltaire` at the revision recorded in `native-dependencies.json`:

```sh
git clone --recurse-submodules https://github.com/evmts/guillotine-mini.git
git clone https://github.com/evmts/voltaire.git
git -C voltaire checkout "$(jq -r .voltaire.revision guillotine-mini/native-dependencies.json)"
cd guillotine-mini
zig build
zig build test-trace
```

If `zig build test-trace` exits `0`, your compiler, linker, and Voltaire crypto libraries all work.

## Wire it into a Zig project

In `build.zig.zon`, declare `guillotine_mini` (and `voltaire` if you construct `Address` or `ZERO_ADDRESS` directly):

```zig
.dependencies = .{
    .guillotine_mini = .{ .path = "../guillotine-mini" },
    .voltaire = .{ .path = "../voltaire" },
},
```

In `build.zig`, import both modules. Voltaire's `primitives` module carries its Rust crypto archive and system libraries, so no `linkLibrary` calls are needed:

```zig
const guillotine_dep = b.dependency("guillotine_mini", .{
    .target = target,
    .optimize = optimize,
});
const voltaire_dep = b.dependency("voltaire", .{
    .target = target,
    .optimize = optimize,
});

exe.root_module.addImport("guillotine_mini", guillotine_dep.module("guillotine_mini"));
exe.root_module.addImport("voltaire", voltaire_dep.module("primitives"));
```

## Your first execution

Our first contract returns the 32-byte word `42` (`0x2a`). In EVM assembly, that takes six instructions — ten bytes of raw bytecode:

```text
00  PUSH1 0x2a   # put 42 on the stack
02  PUSH1 0x00   # memory offset 0
04  MSTORE       # write 32-byte big-endian 42 at memory[0..32]
05  PUSH1 0x20   # return length = 32 bytes
07  PUSH1 0x00   # return offset = 0
09  RETURN       # halt and return memory[0..32]
```

Here is a complete, runnable `src/main.zig`:

```zig
const std = @import("std");
const guillotine = @import("guillotine_mini");
const voltaire = @import("voltaire");

pub fn main() !void {
    const Evm = guillotine.Evm(.{});

    var vm: Evm = undefined;
    try vm.init(
        std.heap.page_allocator,
        null, // host: null uses the EVM's internal maps
        .CANCUN, // hardfork: always pass explicitly
        null, // block context: null uses chain_id = 1 and zeroed fields
        voltaire.ZERO_ADDRESS, // tx.origin
        0, // tx.gasprice
        null, // log level: null keeps default (.none)
    );
    defer vm.deinit();

    const target = voltaire.Address.fromU256(0x42);
    const bytecode = [_]u8{
        0x60, 0x2a, // PUSH1 42
        0x60, 0x00, // PUSH1 0
        0x52,       // MSTORE
        0x60, 0x20, // PUSH1 32
        0x60, 0x00, // PUSH1 0
        0xf3,       // RETURN
    };
    try vm.code.put(target, &bytecode);

    const result = vm.call(.{ .call = .{
        .caller = voltaire.ZERO_ADDRESS,
        .to = target,
        .value = 0,
        .input = &.{},
        .gas = 100_000,
    } });

    std.debug.print("success={} gas_left={} output_len={}\n", .{
        result.success, result.gas_left, result.output.len,
    });
    if (result.output.len == 32) {
        const word = std.mem.readInt(u256, result.output[0..32], .big);
        std.debug.print("word={d} (0x{x})\n", .{ word, word });
    }
}
```

Output:

```text
success=true gas_left=99982 output_len=32
word=42 (0x2a)
```

`3 + 3 + (3 + 3) + 3 + 3 + 0 = 18` gas. `100,000 - 18 = 99,982`.

## Now break it on purpose

Good docs show the failure path too. Change `.gas = 100_000` to `.gas = 10`:

- `PUSH1 0x2a` (3 gas) → 7 left
- `PUSH1 0x00` (3 gas) → 4 left
- `MSTORE` needs **6 gas** (3 base + 3 memory expansion) → **OutOfGas!**

Now `result` comes back with:

```text
result.success    == false
result.gas_left   == 0
result.output.len == 0
result.error_info == "OutOfGas"
```

Compare that with replacing `0xf3` (`RETURN`) with `0xfd` (`REVERT`) at `.gas = 100_000`:

```text
result.success    == false
result.gas_left   == 99982      // unspent gas is refunded on REVERT!
result.output.len == 32         // revert payload is preserved
result.error_info == null       // REVERT is a clean halt, not a CallError
```

<MentalModel title="Three contracts to remember from day one">
1. **`Evm(config)` returns a type, not a value.** Two configs (`Evm(.{})` and `Evm(.{ .stack_size = 512 })`) are distinct Zig types.
2. **Initialize in place.** Always write `var vm: Evm = undefined; try vm.init(...)`. `Evm` holds an arena and internal maps initialized in place.
3. **`hardfork = null` selects `config.hardfork`.** The default config uses Voltaire’s `Hardfork.DEFAULT` (`.OSAKA`). Pass a fork explicitly to override the config for a single instance.
</MentalModel>
