In EVMC ABI 12, `EvmcRevision.experimental` has value `15`. `evmc_adapter.fromHardfork` maps forks newer than Osaka, including `.AMSTERDAM`, to `.experimental`. `evmc_adapter.toHardfork(.experimental)` returns the newest fork in Voltaire.

## Submodule namespaces

`root.zig` also re-exports every underlying file as a namespace: `evm`, `frame`, `host`, `evm_config`, `call_params`, `call_result`, `errors`, `trace`, `inspector`, `tracers`, `simulation`, `live_tracer`, `trace_store`, `debugger`, `flamegraph`, `evmc_adapter`, `opcode`, `dispatcher`.

## What is NOT re-exported

Primitive value types — `Address`, `ZERO_ADDRESS`, `GasConstants`, `AccessList`, `TraceConfig` — belong to `@import("voltaire")` (`voltaire_dep.module("primitives")`). Import `voltaire` directly when constructing addresses or access lists.
