# Build Targets

Transcribed from `build.zig`. Run `zig build --help` for the live list on your checkout.

## Core EVM, native & WASM

| Command | Output / Action |
| --- | --- |
| `zig build` | Runs the default `install` step. `build.zig` attaches no artifact to it, so it produces no library; use `native` or `wasm` |
| `zig build native` | Builds `zig-out/lib/libguillotine_mini.a` (static C ABI archive) |
| `zig build wasm` | Builds `zig-out/bin/guillotine_mini.wasm` (`wasm32-wasi`, `ReleaseSmall`, reactor) |
| `zig build wasm-core wasm-precompile-02` | Builds the modular core and SHA-256. Select other precompiles by hex address |
| `zig build wasm-modular` | Builds the core and all 18 standalone WASI precompile modules |
| `zig build test-wasm` | Runs execution and crypto tests against both reactor builds (Node 22+) |
| `zig build test-wasm-size` | Enforces raw byte budgets on the core, full reactor and individual precompiles |
| `zig build test-trace` | Runs `test_trace.zig` deterministic EIP-3155 native trace regression |
| `zig build unit` | Runs EVM and client module unit tests, `test-osaka-properties`, and `test-spec-runner` |
| `zig build test` | Runs everything in `unit`, plus the `specs` state tests and `nethermind-diff` (skip with `-Dnethermind-diff=false`) |
| `zig build test-osaka-properties` | Runs Osaka execution and precompile property tests (`test/osaka_property_fuzz_test.zig`) |
| `zig build test-spec-runner` | Runs `test/specs/runner.zig` unit tests without fixtures |

## Ethereum specification suites

| Command | Action |
| --- | --- |
| `zig build specs` | Runs `execution-specs` GeneralStateTests |
| `zig build specs-blockchain` | Runs `execution-specs` BlockchainTests |
| `zig build specs-<fork>` | Runs state tests for one fork (`frontier`, `homestead`, `byzantium`, `constantinople`, `istanbul`, `berlin`, `paris`, `shanghai`, `cancun`, `prague`, `osaka`) |
| `zig build specs-<fork>-<slice>` | Runs a granular EIP or opcode slice (e.g., `specs-shanghai-push0`, `specs-cancun-tstore-basic`, `specs-cancun-mcopy`, `specs-byzantium-modexp`) |

The test runner matches `TEST_FILTER` as a plain, case-sensitive substring (`test/utils.zig` `matchesFilter`). Every Berlin, Frontier, Prague, and Osaka sub-step filter in `build.zig` uses regex syntax (`.*`, `(a|b)`, `[^_2]`), so those sub-steps, and the `specs-berlin`, `specs-frontier`, `specs-prague`, and `specs-osaka` steps built from them, select zero tests. Cancun, Shanghai, Byzantium, Constantinople, and Istanbul sub-steps use plain substrings.

## Core EVM & aggregate benchmarks

Run Zig benchmarks with `-Doptimize=ReleaseFast` for accurate timings. Set `BENCH_JSON_OUT=<path>` to write structured JSON reports.

| Command | Scope |
| --- | --- |
| `zig build bench-bytecode` | Bytecode JUMPDEST bitset analysis, lookup & `PUSH` immediate decoding |
| `zig build bench-storage` | Persistent/transient `Storage` & EIP-2929 `AccessListManager` snapshots |
| `zig build bench-frame` | `Frame` lifecycle, stack ops, gas metering & contiguous memory R/W |
| `zig build bench-opcodes` | Per-opcode micro-benchmarks (arithmetic, Osaka `CLZ`, `MCOPY`, `KECCAK256`, `LOG`, etc.) |
| `zig build bench-evm-core` | End-to-end EVM loops, nested `CALL`, EIP-3155 `Tracer`, `RevertDecoder` & precompiles |
| `zig build bench-ffi` | C-FFI `evm_create` / `evm_execute` lifecycle & reused-handle throughput |
| `zig build bench` | Aggregate step running all Core EVM and Zig client benchmarks |
| `node test/wasm.bench.mjs` | WASI reactor instantiation & execution benchmarks (after `zig build wasm`) |
| `bun scripts/bench-summary.ts` | Unified summary & baseline diff across all `.bench-results/*.json` and `**/.bench-result.json` |

## Incremental Smithers targets (`.smithers/WORKSPACE.ts` / `PACKAGE.ts`)

| Command | Action |
| --- | --- |
| `smthrs targets` | List declared targets across all packages |
| `smthrs ci '//...'` | Build, format-check, test and verify the factory; cached results replay |
| `smthrs affected test '//...' --include-exclusive --verbose` | Run only tests and benchmarks whose inputs changed |
| `smthrs test --include-exclusive '//...'` | Run every test and every exclusive benchmark |
| `smthrs test //:bench_opcodes --verbose` | Run one benchmark exclusively |
| `smthrs target //.smithers:factory-write --write` | Regenerate `.smithers/factory.json` and `home.json` after editing `FACTORY.ts` |
| `smthrs run //:bench_summary` | Print aggregated benchmark summary table |

## Build options (`-D`) & environment variables

| Flag / Env var | Effect |
| --- | --- |
| `-Doptimize=ReleaseFast` / `ReleaseSmall` / `ReleaseSafe` | Standard Zig optimization mode |
| `-Dhardfork=<name>`, `-Dmax-call-depth`, `-Dstack-size`, `-Dmax-bytecode-size`, `-Dmax-initcode-size`, `-Dblock-gas-limit`, `-Dmemory-initial-capacity`, `-Dmemory-limit` | Populate the `build_options` module read by `EvmConfig.fromBuildOptions()`. `Evm(.{})` and the C API ignore them |
| `-Dnethermind-diff=false` | Skip Nethermind trie differential test during `zig build test` |
| `-Drefresh-specs=true` | Force regeneration of `execution-specs` fixtures |
| `BENCH_JSON_OUT="<path>"` | Emit structured JSON benchmark metrics for `bench-summary.ts` |
| `TEST_FILTER="<substring>"` | Filter `zig build specs` tests by case-sensitive substring of the test name |
| `TEST_SEQUENTIAL=1` | Run filtered spec tests sequentially for readable divergence logs |
| `INCLUDE_ENGINE_TESTS=1` | Include `blockchain_test_engine` fixtures in `zig build specs` |
