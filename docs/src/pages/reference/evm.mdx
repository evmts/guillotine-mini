# `Evm` & `Frame`

## `Evm(comptime config: EvmConfig) type`

Defined in `src/evm.zig`. Returns a concrete EVM type specialized to `config`.

### Associated types

```zig
pub const CallParams           = call_params.CallParams(config);
pub const CallResult           = call_result.CallResult(config);
pub const AsyncExecutorType    = async_executor_mod.AsyncExecutor(Self, CallParams, CallResult);
pub const CallOrContinueInput  = AsyncExecutorType.CallOrContinueInput;
pub const CallOrContinueOutput = AsyncExecutorType.CallOrContinueOutput;
```

### Lifecycle

```zig
pub fn init(
    self: *Self,
    allocator: std.mem.Allocator,
    h: ?HostInterface,
    hardfork: ?Hardfork,
    block_context: ?BlockContext,
    origin: Address,
    gas_price: u256,
    log_level: ?LogLevel,
) !void

pub fn deinit(self: *Self) void
```

- Initialize in place: `var vm: Evm(.{}) = undefined; try vm.init(...); defer vm.deinit();`.
- `hardfork == null` selects `config.hardfork` (which defaults to `Hardfork.DEFAULT`, `.OSAKA`). The Voltaire enum also includes `.AMSTERDAM`.
- `block_context == null` installs `chain_id = 1`, `block_gas_limit = config.block_gas_limit`, `block_coinbase = ZERO_ADDRESS`, and zero for all other fields.
- `init()` allocates `storage`, `storage_prestate`, `balances`, `nonces`, and `code` inside `self.arena`, so callers can seed pre-state before the first `call()`.
- `deinit()` destroys `self.arena`, releasing all transaction-scoped memory at once.

```zig
pub fn initTransactionState(self: *Self, blob_versioned_hashes: ?[]const [32]u8) !void
```

Resets per-transaction execution state: clears `original_storage`, transient storage, `trace_slots`, `gas_refund`, `pending_state_changes`, `access_list_manager`, `frames` (pre-allocated to `config.max_call_depth + 1`), `logs`, account tracking sets, and snapshot stacks, and copies `blob_versioned_hashes` into `self.arena`. Pre-seeded `balances`, `nonces`, `code`, and non-injector `storage` are preserved; when a `StorageInjector` is active, `storage.storage` is reset back to `storage_prestate`. Invoked automatically by `call()`.

### Execution

```zig
pub fn call(self: *Self, params: CallParams) CallResult
pub fn callWithBytecodeOverride(self: *Self, params: CallParams, bytecode: ?[]const u8) CallResult
pub fn resultErrorName(result: CallResult) ?[]const u8
```

- `call` delegates to `callWithBytecodeOverride(params, null)`.
- `callWithBytecodeOverride` executes any of the six `CallParams` shapes, optionally overriding the top-level target bytecode without mutating `self.code`. Returns borrowed slices allocated in `self.arena`.
- `resultErrorName` returns `null` on success or a Geth-compatible error string (via `inspector.formatErrorName`) on failure.

```zig
pub fn callOrContinue(self: *Self, input: CallOrContinueInput) !CallOrContinueOutput
pub fn inner_call(self: *Self, params: CallParams) CallResult
pub fn inner_create(self: *Self, value: u256, init_code: []const u8, gas: u64, salt: ?u256) errors.CallError!CreateResult
```

- `callOrContinue` drives the async yield/resume state machine (`src/async_executor.zig`).
- `inner_call` and `inner_create` handle nested calls and contract creation with copy-on-write snapshot/rollback, enforcing `config.max_call_depth`, `config.max_initcode_size`, and `config.max_bytecode_size`.

### Pre-call setters, tracing & inspectors

```zig

```

- `setStoragePrestate` seeds a storage slot in both `storage.storage` and `storage_prestate` without counting it as a transaction write.
- `setInspector` attaches a read-only `Inspector` vtable (see [Tracing & Inspectors](/guides/tracing)); `clearInspector` detaches it and resets active frame observation state (`async_observation`, `inspector_frame_id`).

## `BlockContext`

```zig
pub const BlockContext = struct {
    chain_id: u256,
    block_number: u64,
    block_timestamp: u64,
    block_difficulty: u256,
    block_prevrandao: u256,
    block_coinbase: Address,
    block_gas_limit: u64,
    block_base_fee: u256,
    blob_base_fee: u256,
    block_hashes: []const [32]u8 = &[_][32]u8{},
};
```

`block_hashes` stores recent block hashes (up to 256) indexed from the tail matching Python `execution-specs`: `block_hashes[block_hashes.len - (block_number - target_block)]`.

## `Storage`

Defined in `src/storage.zig` (`vm.storage`).

| Method | Semantics |
| --- | --- |
| `get(address, slot) !u256` | With the injector enabled, reads pending writes, then the injector cache, and returns `error.NeedAsyncData` on a miss. With the injector disabled, reads directly from the host if present or from the local map (default `0`). |
| `set(address, slot, value) !void` | Captures `original_storage` on first write in the transaction. With the injector disabled, writes directly to the host if present or to the local map. With the injector enabled, marks the slot dirty, updates the local overlay, and also writes to the host if present. |
| `get_original(address, slot) u256` | Pre-transaction slot value for EIP-2200 / EIP-3529 gas math. |
| `get_transient(address, slot) u256` | Reads EIP-1153 transient slot (`0` if unset). |
| `set_transient(address, slot, value) !void` | Writes EIP-1153 transient slot (reverted on frame rollback; cleared at tx end). |
| `clear_transient() void` | Empties transient storage at transaction boundary. |

## `Frame(comptime config: EvmConfig) type`

Defined in `src/frame.zig`. Holds execution state for a single call context.

### Selected fields

| Field | Type | Meaning |
| --- | --- | --- |
| `stack` | `std.ArrayList(u256)` | LIFO operand stack (bounded by `config.stack_size`, default `1024`) |
| `memory` | `std.ArrayListUnmanaged(u8)` | Contiguous byte-addressed memory |
| `memory_size` | `u32` | Current word-aligned memory length in bytes (bounded by `config.memory_limit`) |
| `pc` | `u32` | Program counter |
| `gas_remaining` | `i64` | Remaining execution gas |
| `bytecode` | `Bytecode` | Raw bytes + `JUMPDEST` bitmap |
| `output` | `[]u8` | Bytes produced by `RETURN` or `REVERT` |
| `return_data` | `[]const u8` | Output from the most recent nested call |
| `stopped`, `reverted` | `bool` | Halt flags |
| `is_static` | `bool` | Read-only mode (`STATICCALL`) |
| `call_depth` | `u32` | Nesting depth (`0` for top-level, bounded by `config.max_call_depth`) |
