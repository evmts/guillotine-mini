Additional Optimizations Shipped

  • handlers_arithmetic.zig: Eliminated u512 division in ADDMOD via overflow-free modular arithmetic; replaced byte-shift loop in EXP gas cost with O(1) @clz.
  • handlers_context.zig & handlers_system.zig: Replaced all per-byte memory copy loops in CALLDATACOPY, CODECOPY, EXTCODECOPY, RETURNDATACOPY, RETURN, REVERT, CREATE/CREATE2, and CALL/CALLCODE/DELEGATECALL/STATICCALL with contiguous @memcpy / @memset helpers.
  • client/db/memory.zig: Reuses existing arena key slices via getOrPut on overwrites (eliminating redundant key dupes) and pre-sizes snapshot maps with ensureTotalCapacity.
  • Benchmark Bug Fixes: Fixed 9 broken adapter.deinit() calls in client/evm/bench.zig, uninitialized stack garbage & DCE in client/db/bench.zig, DCE in client/txpool/bench.zig and client/network/rlpx/bench.zig, NUL-byte padding in client/bench_utils.zig, and 0-key formatting in client/trie/bench.zig.

External Dependency Bottlenecks Identified (../voltaire)

  • BlockStore.setCanonicalHead (O(N²)): Walks back to genesis on every head update and scans the full canonical map in getHeadBlockNumber. Capped client/blockchain/bench.zig to 100 / 500 / 2,000 blocks so benchmarks terminate cleanly while tracking the scaling curve.
  • StateManager checkpoint/revert: Deep-copies the entire state cache on nested checkpoints, capping simulated block throughput in client/evm/bench.zig (~24 MGas/s). Switching to a position-based journal (like client/state/journal.zig) will unlock ~100× higher nested-call throughput.

5. Daily Developer Commands Workflow

# Run ONLY tests + benchmarks affected by your current jj/git diff (replays cached output on hits!)
smithers-build affected test '//...' --include-exclusive --verbose

# Run ONLY affected benchmarks (without non-benchmark unit tests)
smithers-build affected test '//:bench_all' --include-exclusive --verbose

# Run a single module's benchmark (cached across runs; replays table on cache hit with --verbose)
smithers-build test //:bench_opcodes --verbose
smithers-build test //client/rpc:bench --verbose
smithers-build test //client-ts/txpool:bench --verbose

# View unified summary across all collected JSON benchmark artifacts (or diff against a saved baseline)
smithers-build run //:bench_summary
bun scripts/bench-summary.ts --save /tmp/baseline.json
bun scripts/bench-summary.ts --baseline /tmp/baseline.json
