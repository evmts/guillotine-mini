CALL-family gasCost includes the charged forwarded gas. CREATE-family gasCost excludes child execution and code deposit. The trace writer uses hex-string memory as shown in the EIP examples and captures pre-op values of observed slots for the execution address. EIP-3155 · Geth CALL metering · Geth CREATE forwarding

Frame entry identifies built-in precompiles and Zig overrides. Custom WASM precompiles still receive frame entry and exit events. Their classification is resolved by the JavaScript callback during execution, so a custom address can appear as an empty-code call at entry.
