Executive Takeaway: Before this upgrade, guillotine-mini had a single opt-in EIP-3155 struct logger (src/trace.zig) hooked only at Frame.step, with inaccurate nested gasCost, zeroed memSize when memory capture is off, no call-frame or state-mutation hooks, and a stale-read bug in StorageInjector. By introducing a read-only, zero-overhead Inspector vtable (inspired by Geth core/tracing.Hooks, Revm Inspector, and Erigon's 256-bit OnOpcodeMask) plus 7 native tracers/profilers, we reach library-level parity with geth and revm-inspectors in one cohesive architecture.

2. Target Architecture (Zero-Overhead Inspector Pipeline)

Evm & Frame Hot Path
  • Evm.inspector: ?*Inspector
  • Single @branchHint(.unlikely) check when null
  • 256-bit opcode_mask skips onOpcode for frame-only tracers
  • Stable frame_id & parent_id across calls, creates, precompiles & EIP-7702
→
src/inspector.zig
  • onTxStart / onTxEnd
  • onEnter / onExit (call/create/precompile)
  • onOpcode / onOpcodeEnd / onFault
  • onLog, onSelfDestruct, onAccess
  • onStorageChange, onTransientStorageChange
  • onBalanceChange, onNonceChange, onCodeChange
  • MuxInspector (1-pass fan-out)
  • RevertDecoder (Error / Panic ABI)
→
Built-in Consumers
  • Tracer (EIP-3155 JSONL + Geth StructLogger + RingBuffer)
  • CallTracer (Geth tree + Parity flatCallTracer + logs)
  • PrestateTracer (prestate + diffMode pre/post)
  • FourByteTracer (selector-argSize frequency)
  • AccessListInspector (EIP-2930 generator)
  • GasProfiler (opcode histogram + frame incl/excl gas)
  • CoverageInspector (PC hits + JUMPI branch edges)
